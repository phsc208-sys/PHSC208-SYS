Sou acadêmico de **Ciência da Computação** sediado em Belo Horizonte, com foco em desenvolvimento de **automação** e **eficiência**.

Minha abordagem combina a **fundamentação teórica** (Algoritmos, Estruturas de Dados e C++) com a **aplicação prática** (Automação Web, IoT e Parsers). Não apenas escrevo código; construo ferramentas para otimizar processos e resolver problemas reais.

Atualmente focado em:
* 🛠️ **Automação:** Bots e scripts para otimização de workflow.
* 📊 **Dados:** Parsers e analisadores de informação em tempo real.
* ⚡ **Hardware:** Integração software-hardware com Arduino.
